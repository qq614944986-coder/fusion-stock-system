# 双引擎选股择时系统 · 架构与逻辑说明

> 本文档梳理系统的整体架构、功能模块、驱动逻辑与数据获取机制，基于当前代码实况编写（v0.1，2026-08）。
> 参数与规则以 `fusion-system-spec.md` 规格书为源头，本文是代码视角的落地说明。

---

## 1. 系统定位

将两套经过验证的交易体系融合为一个本地化、自动化的每日决策辅助工具：

| 引擎 | 来源体系 | 解决的问题 |
|---|---|---|
| **李致远引擎** | AI 选股择时体系 | 环境判断（情绪温度）+ 选股（板块/主升/打板/尾盘四池）——"**能不能做、做什么**" |
| **老樊引擎** | 老樊交易体系 V2 | 择时信号（均线带/三买三卖）+ 仓位状态机 ——"**什么时候买卖、买卖多少**" |
| **融合决策层** | 规格书 §7 | 两引擎结论冲突时的裁决规则 ——"**最终听谁的**" |

三条设计纪律（全系统强制遵守）：

1. **数据诚实**：任何接口失败 → 标注 `[数据缺失]`，严禁编造数据、严禁用估算值冒充真实值；
2. **老樊参数精确校准**：均线带、买卖点、冷却期等默认值为校准值，禁止随意调整；
3. **条件化建议**：每条建议必须同时包含正向执行条件与反向不执行条件（防止单边误导）。

## 3. 数据获取（core/data_provider.py）

### 3.1 数据源与接口清单（全部来自 akshare 免费接口）

| 接口 | 用途 | 缓存键 |
|---|---|---|
| `stock_zh_a_hist` | 个股日K（前复权，300日） | `daily_代码` |
| `stock_zh_a_spot_em` | 全市场实时快照（现价/量比/换手） | `spot` |
| `stock_market_activity_legu` | 涨跌家数/涨跌停数（情绪输入） | `market_activity` |
| `stock_zh_index_daily` | 上证/深成/创业板指数日K | `index_符号` |
| `stock_board_industry_name_em` | 行业板块行情 | `industry_boards` |
| `stock_sector_fund_flow_rank` | 行业资金流排名 | `sector_fund_flow` |
| `stock_board_industry_cons_em` | 板块成分股 | `cons_板块名` |
| `stock_board_industry_hist_em` | 板块日K | `boardhist_板块名` |
| `stock_individual_fund_flow` | 个股主力净流入 | `fff_代码` |
| `stock_zt_pool_em` | 涨停池（连板数/封板时间/炸板数） | `zt_pool` |
| `stock_zt_pool_zbgc_em` | 炸板池（打板情绪参照） | `zb_pool` |

### 3.2 三项保护机制

1. **本地缓存**：当日拉取成功的数据存 `data/cache/YYYYMMDD/`，当日重跑直接读缓存，不重复请求；
2. **请求节流**：真实网络请求之间强制间隔 ≥0.5 秒（防东财 WAF 风控）；失败后等 3 秒重试 1 次；
3. **降级处理**：重试仍失败 → 返回 `None` 并记录到 `missing` 列表 → 仪表盘对应栏目标注 `[数据缺失]`，绝不阻塞其他模块。

## 4. 李致远引擎（环境判断 + 选股）

### 4.1 情绪温度（sentiment_engine，规格书 §4）

公式：`温度 = 20%×上涨占比 + 20%×涨跌停比 + 20%×指数温度 + 15%×涨停活跃度 + 15%×情绪龙头 + 10%×情绪驱动力`

- 情绪驱动力依赖前日温度（避免循环依赖：先用其余五因子合成基础温度，今日与昨日差 Δ 映射分值：Δ≥+5→90，(0,+5]→70，[-3,0]→50，(-8,-3)→30，≤-8→10）；
- 前日温度缺失 → 驱动力取中性 50 并标注 `[数据缺失]`；
- 情绪龙头：最高连板 ≥5 板得 90，每降 1 板 -10，最高板炸板再 -20，全断板 30。

五区划分与仓位约束（每日全市场操作的总开关）：

| 区间 | 分数 | 操作标签 | 总仓位上限 | 单票上限 | 持仓数上限 |
|---|---|---|---|---|---|
| 冰点区 | 0-34 | 等待止跌（禁止加仓，只减不加） | 20% | 5% | 2 |
| 退潮区 | 35-47 | 控制风险（仅盈利头寸小幅加仓） | 40% | 10% | 3 |
| 震荡区 | 48-61 | 只做最强（只加仓最强龙头） | 50% | 12% | 4 |
| 偏强区 | 62-74 | 适度参与（主升浪确认股可加仓） | 70% | 15% | 5 |
| 高热区 | 75-100 | 防止见顶（禁开新仓，逐步减仓） | 50% | 12% | 4 |

### 4.2 板块筛选（sector_screener，§5.1）

六维度排名（各标准化 0-100 后等权合成）：连板节奏 / 上攻意愿 / 主买占比 / 换手率 / 量能比 / 排名趋势。

- **板块门槛**：个股所属板块当日排名未进前 10 → 主升评分标记"板块门槛未过"；
- 进攻板块（偏强/高热期）：量能比>1.5 且板块连板高度≥3；防御板块（冰点/退潮期）：当日涨幅为正且换手率<3%。

### 4.3 主升个股评分（stock_scorer，§5.2）

八因子评分制（满分 100）：趋势强度 20 / 均线形态 / 量价配合 / 主力资金 / 板块协同 / 龙头地位 / 情绪共振 / 形态扣分等（用 MA5/10/20，与老樊均线带互不影响）。

- **入池标准**：评分 ≥70 且通过板块门槛 → 主升候选池（中线维度）；
- 等级：85+ 极强主升（可重仓）/ 70-84 主升进行（标准仓）/ 55-69 观察关注 / <55 不推荐；
- 特殊标记：短线过热（MA20乖离>19%）、突破确认、回踩买点、板块门槛未过。

### 4.4 打板评分（limitup_scorer，§5.3）

八条硬排除（任一命中直接出局，不进评分）：R1 ST / R2 上市未满60日 / R3 一字板 / R4 当日炸板≥2次 / R5 距20日低点涨幅>50% / R6 无量涨停（量比<0.5）/ R7 无板块协同 / R8 独苗涨停。

六维评分（满分 100，≥60 入打板观察池）：封板时间 20 / 封板强度 20 / 量能结构 15 / 板块协同 20 / 连板高度 15 / 市场情绪 10。

### 4.5 尾盘观察池（eod_watchlist，§5.4）

入选五条件（全部满足）：① 当日涨幅 3%-9.5%（未涨停）或涨停稳封；② 量 >5日均量×1.2；③ 所属板块前 10；④ 收盘价 > 当日均价（14:30 后不回落）；⑤ 阳线实体/振幅 >60%。

执行纪律：买入 14:50-14:55 / 单票 ≤15% / 次日高开>3% 可止盈 / 涨超 8% 不追。

## 5. 老樊引擎（择时 + 仓位）

### 5.1 均线带（ma_band_v2，§6.1-6.2）

- 短期带（攻击带）= **MA5 / MA8 / MA13** 三均线的上下沿；中期带（生命线）= **MA55 / MA60 / MA65**；
- 唯一乖离基准 **BIAS60** = (收盘 - MA60) / MA60 × 100%；
- 附加：量比（当日量/20日均量）、多头/空头排列、均线粘合（带宽<1.5% 视为变盘信号）。

### 5.2 三大买点 × 三大卖点（laofan_signals，§6.3-6.4）

| 信号 | 触发条件 | 置信 | 动作 | 冷却 | 允许状态 |
|---|---|---|---|---|---|
| BP1 乖离买点 | BIAS60 ≤ -25% 首次触达 | 72% | 建 30% 仓 | 20天 | 空仓/离场观察 |
| BP2 突破买点 | 突破中期带上沿≥2% + 量比≥1.5 + 站稳2根K线 | 78% | 建 40% 仓 | 10天 | 空仓/建仓中/离场 |
| BP3 回踩买点 | 多头排列 + 近30日有BP2型突破 + 回踩带沿缩量 | 82% | 加至满仓 | 10天 | 仅建仓中 |
| SP1 乖离卖点 | BIAS60 ≥ +25% 首次触达 | 72% | 减 30% | 20天 | 满仓/建仓中 |
| SP2 破短期带 | 跌破短期带下沿 ≥1% | 75% | 减 50% | 5天 | 满仓/建仓中/减仓中 |
| SP3 破中期带 | 跌破中期带下沿 ≥2% + 1根K线确认 | 88% | **清仓 100%** | 30天 + 15天离场观察 | 持有类全部状态 |

信号优先级：**SP3 > SP2 > SP1 > BP3 > BP2 > BP1**（同日多信号取最高优先级执行）。

### 5.3 持仓状态机（position_manager，§6.6）

五状态：`EMPTY 空仓 → BUILDING 建仓中 → HOLDING 满仓持有 → REDUCING 减仓中 → EXITED 离场观察 → EMPTY`。

- 每只股票一条状态记录，持久化在 `data/positions_state.json`（跨日保留，收盘后运行时刷新冷却期）；
- 信号-状态严格约束（上表"允许状态"列）：状态不符的信号直接拦截并在风险区提示；
- 另维护 `data/score_history.csv` 记录主升评分峰值历史（供"评分较峰值降>15分"卖出规则用）。

### 5.4 九大交易模型（laofan_models，§6.5）

| # | 模型 | 方向 | 基准置信 | 触发分阈值 |
|---|---|---|---|---|
| 1 | 极值反转 | 买入 | 95 | 40 |
| 2 | 突破买点模型 | 买入 | 90 | （联动BP2） |
| 3 | 回踩买点模型 | 买入 | 92 | （联动BP3） |
| 4 | 乖离买点模型 | 买入 | 85 | （联动BP1） |
| 5 | 探路尖兵 | 买入 | 75 | 45 |
| 6 | N式倍量双涨停 | 买入 | 88 | 50 |
| 7 | 异动搓揉线 | 中性/买 | 78 | 40 |
| 8 | 缩量缩波 | 中性 | 80 | 45 |
| 9 | 岛型反转 | 买/卖 | 90 | 45 |

模型 2/3/4 与买点信号联动：BP1/BP2/BP3 的检测结果直接作为对应模型输入。涨跌停判定按板块区分：主板 ±10%（检测阈值 ±9.5%）、创业板/科创板 ±20%（±19.5%）、北交所 ±30%（±29.5%）。

## 6. 融合决策层（fusion_engine，规格书 §7）

### 6.1 买入冲突矩阵（5区 × 3买点 = 15 格全枚举，§7.1）

| 情绪区 \ 买点 | BP1 乖离 | BP2 突破 | BP3 回踩 |
|---|---|---|---|
| 冰点区 | 允许（≤2成试错，熊市只做BP1） | 冻结 | 冻结 |
| 退潮区 | 降级允许（≤3成） | 降级观察（需极强理由） | 条件允许（仅BUILDING加仓） |
| 震荡区 | 正常执行 | 正常执行 | 正常执行 |
| 偏强区 | 正常执行 | 正常执行（积极） | 正常执行（积极） |
| 高热区 | **禁止新仓（铁律：>75禁开新仓）** | **禁止** | **禁止** |

未知组合显式报错，不静默默认。

### 6.2 仓位融合（§7.3）

`个股建议仓位 = min(老樊信号仓位, 情绪区单票上限, 30%硬上限)`
总仓位约束：Σ个股仓位 ≤ 情绪区总仓位上限；持仓数 ≤ min(区上限, 5)。

### 6.3 卖出双轨监控（§7.2，统一优先级 P0 > P1 > P2）

**老樊轨**：SP3→P0（无条件清仓+15天离场观察）、SP2→P1（减50%）、SP1→P2（减30%）。

**李致远轨**：
- P0：硬止损（短线 -5% / 波段 -8%）；跌破 MA20 且无盈利保护；
- P1：主升评分较峰值降 >15 分（减半观察）；板块排名跌出前 10（减半）；情绪崩塌（前日高热≥75 且单日回落 >10 分 → 清仓）；
- P2：止盈（短线 +15% / 波段 +30% 分批）；MA20 乖离 >30%（分批止盈）。

短线/波段的判定：股票当日出现在打板池 → 按短线口径，否则按波段。

### 6.4 条件化建议（§7.4，用户硬性要求）

每条建议 = 现状摘要 + 老樊状态 + **正向执行条件** + **反向不执行条件**（如：高开涨超5%不追；跌破短期带≥1%→SP2减半；跌破中期带≥2%→SP3清仓）。

### 6.5 T0 协同（§6.8，MVP：人工输入日线做T信号）

`python main.py --t0-signal low_absorb|high_throw|none`，按日线趋势（多头/空头/震荡）×T0信号（低吸/高抛）查 3×3 矩阵给出协同结论；BIAS60 ≥ +50% 时低吸置信 -20、高抛 +10（防追高）。

## 7. 主流程驱动逻辑（main.py 每日八步）

```
① 加载配置与自选股（config.yaml + watchlist.yaml）
        ↓
② 情绪温度：涨跌家数+指数+涨停池 → compute_sentiment → 五区判定（追加历史CSV）
        ↓
③ 板块筛选：行业行情+资金流+成分股+板块日K → screen_sectors → 排名/门槛/攻防标签
        ↓
④ 主升候选池：门槛板块成分股 → 预筛(非ST/成交额≥5000万/当日上涨/上限50只)
        → score_stock 八因子 → ≥70且过门槛入池
        ↓
⑤ 打板观察池：涨停池 → R1-R8硬排除 → 六维评分 → ≥60入池
        ↓
⑥ 尾盘观察池：门槛板块当日涨幅≥3%的成分股 → check_eod 五条件筛选
        ↓
⑦ 老樊引擎循环（持仓+关注+候选前10）：
   刷新冷却期 → 均线带计算 → 信号检测 → 九大模型评分
   → 融合买入(冲突矩阵+仓位) → 融合卖出(双轨) → T0协同 → 条件化建议
        ↓
⑧ 融合输出：候选池挂老樊信号 → 三池Top3交叉验证精选 → 渲染仪表盘HTML
```

关键实现细节：

- 日K不足 66 条（覆盖 MA65）→ 该股标注 `[数据缺失]`，不参与老樊计算；
- 板块成分股拉取按当日涨幅排序取前 30 个板块（`sector_scan_limit`，控制调用量）；
- 做T信号 `--t0-signal` 缺省为 none。

`python backtest.py --code 603019 --days 250`：拉取长历史（预热均线，窗口前多取 70 根），逐日重放均线带/三买三卖/状态机/冷却期；净值口径为 MVP：信号按当日收盘价成交，权益 = 现金 + 仓位%×当日涨跌幅贡献。
