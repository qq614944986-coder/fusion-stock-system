# 双轨选股系统 · 设计与架构（整合版）

> 版本 v1.0 · 2026-08 · 融合「左侧预期差低吸」+「右侧主升趋势跟随」双轨，并把老樊体系重建为双轨统一的执行与风控骨架。
> 聚焦 AI 算力产业链 / 创新药 / 互联网（仅主板）。本文同时是需求与架构文档，工程可执行。
> 相关：本文件是选股与架构主体；`docs/系统架构与逻辑说明.md` 保留老樊引擎工程实现细节，作为执行骨的实现说明。

## 一、定位与总纲

### 1.1 双轨
- **左轨 · 预期差低吸**：在共识形成前，识别"定价与产业趋势脱钩"的标的，低吸埋伏。
- **右轨 · 主升趋势跟随**：跟随有产业逻辑与板块共振支撑的主升浪，但用质量门槛杜绝"见强就上"。

### 1.2 总纲：alpha 从哪来
选股的 alpha 只来自三类可被反复收割的偏差：
1. **情绪超调**（跌过头/涨过头）——左轨吃超跌，右轨避超涨。
2. **信息滞后**（盈利超预期、一致预期上修、产业拐点传导滞后）——左轨吃预期差。
3. **结构错位**（同一景气链条只抬一头）——左右轨分别处理龙头与补涨。

**分工总则**：新策略决定"选什么"（左轨选低吸目标、右轨选主升目标）；老樊决定"何时进、进多少、何时退"（BP/SP + 状态机）。二者是"选"与"择时"，不是并列加层。

## 三、左轨：预期差低吸

### 策略 L1 超跌反转（吃情绪超调）→ 由老樊 BP1 直接执行
| 信号 | 判定口径 |
|---|---|
| 深跌到位 | 近60日跌幅进入近3年深分位（前20%），且相对沪深300超额跌>10% |
| 量能枯竭 | 下跌段量能萎缩到5日均量50%以下、ATR收缩出清 |
| 支撑有效 | 触及老樊中期带下沿/前低获支撑不破位 |
| 资金回补 | 首根温和放量阳线 + 龙虎榜机构/陆股通/融资任一净买 |
| **介入执行** | 用 BP1（BIAS60首次触达≤-25%）作为左侧买入执行，状态机建仓30% |

### 策略 L2 预期差修复（吃信息滞后）→ 由"温和左侧布局"判据执行
| 信号 | 判定口径 |
|---|---|
| 一致预期上修 | 研报对近两年净利近4周全线上调（负转正、斜率转正） |
| 盈余惊喜 | 业绩预告/快报中值>当前一致预期（SUE>0） |
| 估值低位 | PE/PEG/PB 处近3年分位<40% |
| 筹码转好 | 机构调研密度↑、回购、无大股东减持 |

### 策略 L3 产业拐点埋伏（吃结构错位/传导滞后）
利用赛道"上游→中游→下游"传导滞后 + 赛道领先指标（见第六节），在龙头未动时埋伏"受益未定价"的环节。终判靠人工确认订单/业绩。

### 新模块：温和左侧布局判据（左轨 L2/L3 的先手执行）
老樊 BP1（乖离≤-25%）很深，只覆盖 L1。L2/L3 埋伏点更早更温和，需下述判据先行：
- 估值分位低（<40%）；
- 缩量企稳（量能萎缩 + 不再创新低）；
- 资金回补信号（龙虎榜/陆股通/融资/机构调研任一转正）。
三者齐备即打"温和左侧布局"标，仓位置轻（低于 BP1/BP3）；随后若 BP1 更深触发或 BP2/BP3 确认，再升级仓位。

## 四、右轨：主升趋势跟随

### 策略 R1 趋势确立（吃动量持续）
MA结构收敛发散 + 海龟式通道突破回踩确认 + 回调缩量 + ATR移动止损（跟趋势非追顶）。

### 策略 R2 量价与换手结构（非追高）
主升段换手适中（3%-15%）、BIAS20未过热（<19%）、缩量新高排除→避免顶部接盘。

### 策略 R3 板块与龙头结构
只做板块 20/60 日 MA 多头内的个股、板块共振（≥2只新高）、龙头-补涨高低切。

### 新模块：主升质量门槛（右轨统一滤网）
旧右轨"见强就上"的毒瘤在此修去：
| 门槛 | 判定 |
|---|---|
| 板块趋势前置 | 板块 20/60 日 MA 多头（剔除孤立逆势） |
| 量价健康 | 排除量比>1.8而涨幅<1%（滞涨）、换手>25%（极端分歧） |
| 乖离约束 | BIAS20<19% 才可跟随，过热降级 |
| 板块共振 | 同板块≥2只走强 或 处景气传导受益位 |
| 产业锚挂钩 | 可映射到赛道产业驱动（否则降级） |

## 五、三大赛道信号库

### AI 算力产业链
- 传导时序：GPU→光模块→PCB/CCL→服务器/液冷→IDC→电力（滞后期1-2季，是左轨窗口）。
- 领先指标：存储涨价、CoWoS产能、云厂(微软/谷歌/Meta/亚马逊)capex、智算集采、国产算力(昇腾/海光)政策。
- 位置：左轨埋伏"传导未到、龙头未动"环节；右轨跟随"景气主线确立、板块共振"。
- 主板池：中际旭创/新易盛/天孚/剑桥、沪电/深南/生益/景旺、工业富联/浪潮/英维克/高澜、沃尔核材、欧陆通、润泽/宝信。

### 创新药
- 驱动：临床数据读出 + BD/license-out 出海，估值弹性在事件。
- 领先信号：数据读出日历（III期/关键II期/FDA审评）、BD交易密度回暖、投融资额回暖、医保/审批提速。
- 位置：左轨做"数据读出前2-6个月"埋伏窗口；右轨做"落地确认后"跟随。数据读出为双刃剑，左轨小仓位 + 期权思维。
- 主板池：恒瑞/百济/信达/君实/荣昌/贝达/恩华/CXO对应主板标的。

### 互联网
- 驱动：流量×变现率×利润率，中期看利润拐点 + 政策 + 股东回报 + AI 重估。
- 领先信号：利润率先于收入修复、政策缓解（版号/监管）、回购分红加码、AI落地验证。
- 位置：左轨做"利润率拐点+政策+回购"估值修复；右轨做"业绩确认+AI重估"。
- 主板池：腾讯/美团/阿里/百度/快手/网易/分众/三七等（以主板可交易为准）。

## 六、老樊执行骨架（融合核心）

老樊体系在此重建角色——从"独立的选股择时"变为"双轨统一的执行与风控骨架"：

| 老樊能力 | 新策略中的角色 |
|---|---|
| BP1 乖离买点 | **左轨 L1** 的左侧买入（超跌介入，状态机建仓 30%） |
| BP2 突破买点 / BP3 回踩买点 | **右轨** R1/R2 的介入与趋势中继加仓（45%/回踩冲向满仓） |
| SP1/SP2/SP3 | 双轨**统一风控**：乖离止盈→破短期带减仓→破中期带清仓+离场观察 |
| 状态机 EM→BU→HO→RE→EX | 双轨**统一仓位演进**，含冷却期与状态约束 |
| 九大模型 | 硬判据（1/5/6/8 与联动 2/3/4）作参考；近似形态（7/9）降权，不作主判 |

### 融合映射表
| 机会类型 | 选择逻辑 | 介入执行 | 风控/退出 |
|---|---|---|---|
| 左轨 L1 超跌反转 | 异动雷达+预期差校验 | 老樊 BP1 | SP/状态机 |
| 左轨 L2/L3 预期差/拐点 | 异动雷达+温和左侧布局判据 | 温和布局(先行)+BP1(兜底) | SP/状态机 |
| 右轨 R1-R3 主升跟随 | 主升质量门槛+赛道/板块 | 老樊 BP2/BP3 | SP+ATR移动止损 |
| 双轨（左先埋伏+右后确认） | 信号双标记 | 温和布局→BP2/BP3 升级 | SP+状态机 |

## 十、验收标准与指标

- 右轨不再追高：右轨标的 BIAS20 过热率显著低于旧主升；介入位相对 30 日高位乖离偏低。
- 左轨先手：左轨候选含机构调研/一致预期上调/龙虎榜等非共识证据覆盖率提高。
- 双轨衔接：存在"左埋伏→右确认"双轨标的，形成时间先后衔接。
- 证据可回溯：每卡片≥1 条数据源证据；产业逻辑标注"系统提示/人工验证项"。
- 复盘闭环：观察池次日胜率/冲高率分赛道、分轨滚动验证。
- 老樊有效执行：每机会卡片能明确匹配到 BP/温和布局/SP 的具体执行信号（不悬空）。

## 十一、风险与局限

- 系统不真正理解产业：产业逻辑是模板映射，终判靠使用者深度研究。
- 预期差用代理指标，不等于精确估值。
- 免费源有延迟与覆盖缺口；事件日历需人工维护。
- 左轨"埋伏"是概率游戏：需小仓位 + 严格风控，数据读出等事件是双刃剑。
- 九大模型中搓揉线/岛型为规则近似，降权使用，不主导决策。
