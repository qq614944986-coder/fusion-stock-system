# 双引擎选股择时系统 · 使用说明

融合「李致远 AI 选股择时体系（情绪温度/板块筛选/主升浪评分）」与「老樊交易体系 V2（均线带/三买三卖/九大模型/状态机）」的本地选股择时辅助工具。

**每日收盘后运行一次，生成单页 HTML 仪表盘。**

---

## 1. 安装依赖（一条命令）

已安装 Python 3.10 及以上后，在本目录打开命令行执行：

```
pip install akshare pandas numpy PyYAML jinja2
```

> 无需数据库、无需服务器，全部数据本地缓存到 `data/cache/`。

---

## 2. 如何修改自选股 / 持仓

用记事本打开 `config/watchlist.yaml`，按下面示例编辑：

```yaml
positions:            # 持仓股（参与老樊状态机与仓位建议）
  - code: "603019"    # 股票代码（6位）
    name: "中科曙光"   # 名称（随意写，仅显示用）
    cost: 61.50       # 你的成本价（用于止盈止损提示，可留空）
    shares: 100       # 持股数量（可留空）

watching:             # 关注股（只出买卖点信号，不出仓位建议）
  - code: "002643"
    name: "万润股份"
```

- 增加/删除股票：整段复制或删除上面 `- code:` 开始的 4 行即可。
- 持仓股的实际状态（建仓中/满仓/离场观察）由系统记录在 `data/positions_state.json`，一般无需手改；如需重置，删除该文件即可（下次运行自动重建）。

## 3. 每日如何运行

### 方式一：双击一键运行（推荐）

双击本目录下的 `run_daily.bat`，全程自动：

1. 自动把运行过程完整写入日志 `logs\run_日期_时间.log`；
2. 成功 → 自动打开今日仪表盘（浏览器）；
3. 失败 → 窗口停住显示原因，并把错误日志存到 `logs\last_error.log`。

> 排查方法：把 `logs\last_error.log` 拖进 Trae 对话框，AI 直接帮你定位问题。
> 最近一次成功日志在 `logs\last_success.log`。

### 方式二：命令行运行

```
python main.py
```

做 T 人工信号（可选）：

```
python main.py --t0-signal low_absorb    # 当日做了低吸
python main.py --t0-signal high_throw    # 当日做了高抛
```

### 方式三：Windows 任务计划（每个交易日收盘后自动运行）

1. 按 `Win` 键搜索「任务计划程序」并打开；
2. 右侧点「创建基本任务」→ 名称填「双引擎选股」→ 下一步；
3. 触发器选「每天」，时间设为 **15:30**（收盘后）→ 下一步；
4. 操作选「启动程序」→ 程序脚本填本目录的 `run_daily.bat`，
   添加参数填 `silent`（静默模式：不弹窗、只写日志）；
5. 「起始于」填写本目录完整路径（如 `D:\TRAE SOLO CN\TRADING\fusion-stock-system`）→ 完成。

> 周末/节假日运行无害：系统按最近交易日数据处理，数据当日已缓存则不重复请求。

## 4. 如何阅读仪表盘（六个面板）

| 面板 | 内容 | 怎么用 |
|---|---|---|
| ① 情绪温度表盘 | 六因子合成的当日情绪温度（0-100）与五区分类 | 先看这里：**决定今天能不能做、总仓位上限**。冰点/退潮=控仓观望，高热=禁新仓防见顶 |
| ② 板块轮动榜 | 板块六维度排名（连板节奏/上攻意愿/主买占比/换手/量能比/排名趋势） | 决定**做什么方向**：只做排名前10板块内的个股 |
| ③ 候选池总览 | 主升池（评分≥70）/ 打板池（评分≥60）/ 尾盘池，按短线/中线分组 | 决定**关注什么**：结合评分与板块门槛筛选 |
| ④ 持仓监控 | 每只持仓的老樊状态机状态、均线带K线图（短期带+中期带双带）、BIAS60、条件化建议 | **核心面板**：每条建议都含「正向条件 + 反向不执行条件」，双向核对后再操作 |
| ⑤ 信号日历 | 近20日 BP（买点）/SP（卖点）触发记录 | 回看信号节奏，验证是否处于冷却期 |
| ⑥ 风险提示 | 数据缺失说明、冷却期提醒、纪律条令 | 数据缺失项不会编造数值，对应结论需人工补充判断 |

**五区仓位速查**：冰点≤2成 · 退潮≤4成 · 震荡≤5成 · 偏强≤7成 · 高热≤5成且禁新仓。
**信号优先级**（同日多信号时）：SP3 > SP2 > SP1 > BP3 > BP2 > BP1。

## 5. 历史回放（验证信号，可选）

对任意股票回放老樊引擎近250日信号与净值曲线：

```
python backtest.py --code 603019 --days 250
```

输出 `output/backtest_代码_timeline.csv`（逐日状态/净值）与 `_signals.csv`（信号时间轴）。

## 6. 版本管理（GitHub）

本项目已初始化为 git 仓库，日常版本管理全部交给 Trae 完成：

- **保存一个版本**：在 Trae 对话说「提交当前修改」，AI 自动生成规范的提交说明；
- **查看历史**：说「查看最近的提交记录」；
- **回退/对比**：说「对比我改了什么」「回到上一个版本」。

**隐私保护**：真实持仓文件 `config/watchlist.yaml` 已通过 `.gitignore` 排除在版本库之外
（永不联网），GitHub 上只有代码和不含持仓的模板 `config/watchlist.yaml.example`。
运行数据、缓存、日志、仪表盘同样不入库。仓库仍建议设为**私有（Private）**。

## 7. 结合 Trae 使用（日常用法）

用 Trae 打开 `fusion-stock-system` 文件夹（文件 → 打开文件夹），之后：

| 场景 | 在 Trae 里怎么说 |
|---|---|
| 运行出错 | 「读取 logs 目录最新的错误日志，帮我排查今天运行失败的原因」 |
| 分析今日结果 | 「打开今日仪表盘的数据，总结今天的情绪、板块和持仓建议」 |
| 改自选股 | 「把 600519 加进 watchlist 持仓，成本 1500，100 股」（AI 直接改文件） |
| 调研某只股票 | 「用老樊引擎分析 603019 现在是什么状态，有什么买卖点」 |
| 保存版本 | 「提交当前修改」 |
| 历史验证 | 「回放 603019 近 250 日的信号」 |
| 改参数 | 「把 BP2 确认 K 线数改成 3」（改前 AI 会对照规格书提醒影响） |

> 提示：Trae 能直接读写本项目所有文件、运行测试和脚本，你不需要记住任何命令，
> 用自然语言描述要做的事即可。
